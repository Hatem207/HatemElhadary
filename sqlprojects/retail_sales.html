Project Overview

This SQL project analyzes retail sales data to explore sales performance, customer behavior, product categories, and purchasing patterns. The analysis was performed using SQL queries to clean, explore, and extract meaningful insights from the dataset.

Database Structure

The project uses a retail sales table containing transaction, customer, product, and sales-related information.

Data Cleaning

The dataset was checked for missing values in important fields before performing the analysis. 

SELECT *
FROM retail_sales
WHERE transactions_id IS NULL
   OR sale_date IS NULL
   OR sale_time IS NULL
   OR gender IS NULL
   OR category IS NULL
   OR quantity IS NULL
   OR cogs IS NULL
   OR total_sale IS NULL;

SQL Analysis

01. Total Number of Sales

How many transactions are recorded in the dataset? 

SELECT COUNT(*) AS total_sales
FROM retail_sales;
SQL Concepts: COUNT(), SELECT

02. Sales by Category

What is the total sales amount for each product category? 

SELECT
    category,
    SUM(total_sale) AS total_sales
FROM retail_sales
GROUP BY category
ORDER BY total_sales DESC;
SQL Concepts: SUM(), GROUP BY, ORDER BY

03. Average Customer Age

What is the average age of customers purchasing from the Beauty category? 

SELECT
    AVG(age) AS average_age
FROM retail_sales
WHERE category = 'Beauty';
SQL Concepts: AVG(), WHERE

04. High-Value Transactions

Identify transactions where the total sale exceeded 1000. 

SELECT *
FROM retail_sales
WHERE total_sale > 1000;
SQL Concepts: Filtering, Comparison Operators

05. Top 5 Customers

Which customers generated the highest total sales? 

SELECT
    customer_id,
    SUM(total_sale) AS total_sales
FROM retail_sales
GROUP BY customer_id
ORDER BY total_sales DESC
LIMIT 5;
SQL Concepts: SUM(), GROUP BY, ORDER BY, LIMIT

06. Unique Customers by Category

How many unique customers purchased from each category? 

SELECT
    category,
    COUNT(DISTINCT customer_id) AS unique_customers
FROM retail_sales
GROUP BY category;
SQL Concepts: COUNT(), DISTINCT, GROUP BY

07. Best-Selling Month

Identify the month with the highest average sales for each year. 

SELECT *
FROM (
    SELECT
        EXTRACT(YEAR FROM sale_date) AS year,
        EXTRACT(MONTH FROM sale_date) AS month,
        AVG(total_sale) AS avg_sale,

        RANK() OVER (
            PARTITION BY EXTRACT(YEAR FROM sale_date)
            ORDER BY AVG(total_sale) DESC
        ) AS rank

    FROM retail_sales
    GROUP BY 1, 2
) AS t1

WHERE rank = 1;
SQL Concepts: Subqueries, EXTRACT(), AVG(), RANK(), Window Functions

08. Sales by Gender and Category

Compare the number of sales across genders and product categories. 

SELECT
    gender,
    category,
    COUNT(transactions_id) AS sales
FROM retail_sales
GROUP BY gender, category
ORDER BY category, sales DESC;
SQL Concepts: COUNT(), GROUP BY, Multiple Dimensions

09. Sales by Time Shift

Classify transactions into Morning, Afternoon, and Evening shifts. 

SELECT
    CASE
        WHEN sale_time <= '11:59:59'
            THEN 'Morning'

        WHEN sale_time <= '17:00:00'
            THEN 'Afternoon'

        ELSE 'Evening'
    END AS shift,

    COUNT(*) AS number_of_orders

FROM retail_sales
GROUP BY shift;
SQL Concepts: CASE WHEN, Time Analysis, GROUP BY
